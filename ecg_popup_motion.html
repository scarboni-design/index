Implementation spec

Enter (in)opacity 0 → 1, translateY -10px → 0
Duration (in)400ms
Easing (in)ease-out
Visible time~3000ms before exit starts
Exit (out)opacity 1 → 0, translateY 0 → -6px
Duration (out)400ms
Easing (out)ease-in
Manual dismissClicking the X cancels the timer and immediately triggers the same exit animation
toast-animation.css + .js 
/* CSS */
.toast {
  opacity: 0;
  transition: none;
}

/* JS — call showToast() to trigger */
function showToast(el) {
  // reset to starting state
  el.style.transition = 'none';
  el.style.opacity = '0';
  el.style.transform = 'translateY(-10px)';
  void el.offsetWidth; // force reflow

  // enter
  el.style.transition = 'opacity 400ms ease-out, transform 400ms ease-out';
  requestAnimationFrame(() => {
    el.style.opacity = '1';
    el.style.transform = 'translateY(0)';
  });

  // exit after 3000ms visible
  setTimeout(() => {
    el.style.transition = 'opacity 400ms ease-in, transform 400ms ease-in';
    el.style.opacity = '0';
    el.style.transform = 'translateY(-6px)';
  }, 3000);
}

// Manual dismiss (X button): cancel timer, run exit immediately
// implementation detail: store the setTimeout id and clearTimeout()
// on click, then re-run the exit block above.
