Dots Fade

Three dots animating via opacity only — no movement, no bounce. Chosen for its restraint and clinical neutrality. Works on dark and light surfaces.

Preview

Dark · Orange #FB8500
Dark · White #FFFFFF

Specs

Dot size 6 × 6 px
Gap between dots 8 px
Dot shape border-radius: 50%
Color · variant A
#FB8500
Color · variant B
#FFFFFF
Opacity range 0.15 → 1 → 0.15
Duration 1.4s per cycle
Easing ease-in-out
Stagger delay dot 1: 0s · dot 2: 0.2s · dot 3: 0.4s
Loop infinite
Animation property opacity only — no transform

Code

HTML + CSS 
<!-- Dots Fade · Loading Indicator -->
<!-- Variant: orange (#FB8500) or white (#FFFFFF) via --dot-color -->

<div class="dots-fade">
  <span class="dot"></span>
  <span class="dot"></span>
  <span class="dot"></span>
</div>

/* ── CSS ── */

.dots-fade {
  display: flex;
  gap: 8px;
  align-items: center;
}

.dots-fade .dot {
  width: 6px;
  height: 6px;
  border-radius: 50%;
  background: var(--dot-color, #FB8500); /* override with #FFFFFF for white variant */
  animation: dotFade 1.4s ease-in-out infinite;
}

.dots-fade .dot:nth-child(2) { animation-delay: .2s; }
.dots-fade .dot:nth-child(3) { animation-delay: .4s; }

@keyframes dotFade {
  0%, 100% { opacity: 0.15; }
  40%       { opacity: 1; }
}

/* ── Reduced motion ── */

@media (prefers-reduced-motion: reduce) {
  .dots-fade .dot {
    animation: none;
    opacity: 1;
  }
}
