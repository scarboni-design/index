Column Header Sort States

Anchor · Exam list · Component: table header sort control

Overview

Column headers in the exam list table need a visible, unambiguous indicator of which column the table is currently sorted by, and in which direction.

Interaction Logic

Click #Resulting state
1st clickColumn becomes active, sorted ascending. Pill appears behind label, up arrow turns orange.
2nd click (same column)Column stays active, sorted descending. Down arrow turns orange, up arrow returns to muted.
3rd click (same column)Sort clears. Pill disappears, both arrows return to muted. Table returns to default order (by acquisition_date, descending).
Click on a different columnPreviously active column resets immediately (no transition delay). New column becomes active at ascending.

Only one column can be sorted at a time — this is single-column sort, not multi-column. No modifier key (Shift, Ctrl) changes this behavior.

Interaction logic (JS reference)

sort-cycle.js 
// Pseudocode — adapt to your framework/state management
function handleHeaderClick(column) {
  if (currentSort.column !== column) {
    // switching to a new column: always start ascending
    currentSort = { column: column, direction: 'asc' };
  } else if (currentSort.direction === 'asc') {
    currentSort = { column: column, direction: 'desc' };
  } else {
    // third click on the same column: clear sort entirely
    currentSort = { column: 'acquisition_date', direction: 'desc' }; // default
  }
  applySortToTable(currentSort);
}
